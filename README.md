# Home Credit Risk ML

End-to-end machine learning system for predicting credit default risk.

## Project goals

- Explore and validate multi-table financial data
- Build reproducible feature engineering pipelines
- Compare and evaluate classification models
- Calibrate predicted probabilities
- Analyze model errors and explanations
- Serve predictions through FastAPI
- Store prediction history in PostgreSQL
- Containerize the system with Docker
- Monitor data quality, drift, and API performance
